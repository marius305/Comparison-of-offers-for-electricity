# Comparison of offers for electricity
Given the estimated monthly electricity consumption of a consumer, this C++ application determines which are the most advantageous types of subscription for that consumer (in terms of the cost of the monthly bill).
The tariffs taken into account by the application are those existing between January and February 2024.
## Compile and run
The application can be found in the file 'code 217.cpp' and is written in the C++ language. Consequently, an IDE that supports applications written in C++ (for example Codeblocks) will be used for compilation and running.
## Input data
Enter the estimated monthly electricity consumption (in kWh) from the keyboard.
## Output data
This application determines and displays which are the most advantageous types of subscription for that consumer (in terms of the cost of the monthly bill).
## Utility
This application is useful for any electricity consumer. With its help, a consumer can find out which energy supplier and what type of subscription it is advisable to choose in order to make important savings on the payment of the electricity bill. The higher the estimated monthly consumption, the greater the savings will be.
